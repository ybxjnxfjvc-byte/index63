# Mini threat model — index63

## Scope

Публичный учебный кейс `ИПР — система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — HTTP / сеть / локальная диагностика

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Небезопасный HTTP | В коде остаются http:// или ws:// внешние endpoint | Статический аудит URL; localhost исключается отдельно |
| T2 | Неожиданные внешние endpoint | Кейс обращается к неизвестному домену | Инвентаризация всех URL/доменов перед публикацией |
| T3 | Лишний локальный порт | Учебный сервис слушает 0.0.0.0 вместо localhost | Bind 127.0.0.1 по умолчанию |
| T4 | Неограниченный timeout | Запрос может зависнуть | Явные таймауты и обработка ошибок |
| T5 | Смешение границ | Публичный сайт трактуется как часть внутренней сети компании | Документированные trust boundaries |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
